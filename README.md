### 竞品分析的三条核心结论

1. **育儿与宠物方向的开源生态极不成熟**：育儿最高 43★（`dadAI`），宠物 AI 的 star 中位数 0–2；**没有任何项目把「档案 + 科普 + 急症引导 + RAG + 高危拦截」五件事同时做齐**。
2. **「多 Agent 协同」不构成竞争壁垒**：LangGraph / CrewAI / OpenAI Agents SDK 全是 MIT，任何竞品一周内可同等获得 → 已在 §1.3 明确**禁止当作对外卖点**。
3. **真正能立住的是两块**：育儿 × 宠物**交叉场景**（全站仅 2 个 0★ 仓库）+ 中文家庭场景的**危机风险分级 / 干预话术 / 转介链路**（开源完全空白）。

### 许可提醒（须进法务清单）

- 开源里**「最像Babe宝伴」的几个项目全部没有 LICENSE**（`pet-first-aid-assistant`、`veterinary_agent`、`feline-health-advisory`）→ 只能学思路，不能抄代码或数据。
- **唯一可商用的知识资产**：`Bio-Vet/pet-food-safety`（数据 CC BY 4.0 / 代码 MIT，101 条毒物数据，5 物种独立判定）。

- `Dify` 自定义许可**禁多租户 SaaS 对外服务**；`microsoft/autogen` 是 **CC-BY-4.0**。
