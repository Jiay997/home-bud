## 0. 使用说明

### 0.1 字段口径

| 字段 | 说明 |
| --- | --- |
| `kb_id` | 本文献级条目的建议编号，拆分后的业务条目另行编号 |
| `kb_kind` | 对应项目五类知识库：`child` 育儿 / `pet` 宠物 / `assessment_pool` 题库 / `risk_lexicon` 高危词库 / `sensitive_lexicon` 敏感词库 |
| `source_type` | 统一为“公开文献改写”；机构授权内容需另行登记授权书 |
| `source_level` | 项目 DR-10 口径：`guide` 权威指南 / `academic` 学术 / `institution` 机构 / `media` 媒体 |
| `获取状态` | 全文公开 / 摘要或目录公开 / 需购买或授权 / 无法核验 |
| 证据标签 | `机构共识` / `有争议` / `证据有限`，每条结论必带其一 |

### 0.2 四层引用架构（与项目知识库上线标准对齐）

1. **强制/监管层**：GB 10765/10766/10767-2021、农业农村部公告第 20 号；引用时必须写版本年份与实施日期。
2. **机构指南层**：国家卫健委指南、AAP、CDC、AAHA、AAFP、WSAVA、FEDIAF；作为主流结论的主体来源。
3. **学术专著/方法学层**：Bright Futures、NRC、Kirk's、Zubler 2022；用于溯源与标注证据等级。
4. **争议标注层**：体罚与管教、猫绝育时机、室内/散养猫、生食喂养；输出时必须带争议标签。

### 0.3 入库硬规则

- `preconditions`（适用前提）不得为空；缺少月龄/阶段、物种、健康状况任一要素即不得上架。
- 不得输出诊断、处方、用药剂量；涉及发育迟缓、营养性疾病、宠物急症时只做“建议就医/转介”。
- 引用表述用“符合 AAFCO 营养档案”，不得写“AAFCO 认证”；FEDIAF 同理，不得写“欧盟认证”。
- 指南类条目复核周期建议 12 个月；高危类目（中毒、窒息、虐待、自伤等）6 个月；到期未复核按项目规则降权/下架。
- 本文件是“文献级索引”，不是可直接对外发布的科普正文；对外条目须按覆盖矩阵拆分并逐条审核。

### LIT-01 《3 岁以下婴幼儿健康养育照护指南（试行）》

| 字段 | 内容 |
| --- | --- |
| 建议 `kb_id` | KB-LIT-001 |
| `kb_kind` / `domain` | `child` / `child` |
| 建议 `topic_category` | 生长发育监测、喂养与营养、交流与玩耍、生活照护、伤害预防、常见健康问题 |
| `age_band` | 0–6 月、6–12 月、1–3 岁 |
| `source_type` / `source_level` | 公开文献改写 / `guide` |
| 获取状态 | **全文公开**（国家卫健委网页、中国政府网、部分省级卫健委 PDF） |
| 来源 | 国家卫生健康委办公厅，国卫办妇幼函〔2022〕409 号，2022 年 11 月印发（公开日期 2022-11-28） |
| 官方链接 | https://www.nhc.gov.cn/wjw/c100378/202211/72dfcfd2eb7d43288069c28e2539b29f.shtml ；解读：https://www.nhc.gov.cn/fys/c100077/202211/6e6de36e041f4308a0b1d887ec9a1eb4.shtml |

**摘要**：中国 0–3 岁养育照护的现行官方指导文件，依据 WHO/UNICEF《养育照护框架》五要素、结合中国实际制定。文件由“重要意义—基本理念—咨询指导内容”三部分和 4 个附件组成，面向医疗机构儿童保健人员与家庭养育人，强调回应性照护与早期学习机会。

**核心观点**

- 养育照护五要素：良好的健康、充足的营养、回应性照护、早期学习机会、安全保障；中国文件将其落地为 6 个咨询指导方面：生长发育监测、营养与喂养、交流与玩耍、生活照护指导、伤害预防、常见健康问题的防控及照护。
- 8 条基本理念：重视早期全面发展；遵循生长发育规律和特点；给予儿童恰当积极的回应；培养自主和自我调节能力；注重亲子陪伴和交流玩耍；将早期学习融入养育照护全过程；创建良好家庭环境；认真学习提高养育素养。
- 养育人（父母）是第一责任人；医疗机构通过养育风险筛查、咨询指导、父母课堂、亲子活动、随访提供支持。
- 4 个附件：0～3 岁儿童生长发育监测图；儿童心理行为发育问题预警征象筛查表；6～24 月龄婴幼儿辅食添加要点；婴幼儿亲子交流与玩耍要点。

**可直接引用的关键结论（改写）**

1. 0–3 岁是大脑与身体快速发育的关键期，养育照护应同时覆盖健康、营养、回应性照护、早期学习与安全。〔适用：0–3 岁一般人群；`机构共识`〕
2. 回应性照护的核心是观察婴幼儿的眼神、表情、动作、声音、手势和口头请求，并及时、恰当回应。〔适用：0–3 岁；`机构共识`〕
3. 早期学习机会可通过亲子游戏、亲子阅读、亲子交流（身体接触、肢体语言、语言表达）提供，重点在陪伴与互动，而非提前学业训练。〔适用：0–3 岁；`机构共识`〕
4. 儿童心理行为发育问题预警征象筛查表用于“筛查提示”，不是诊断工具；发现预警征象应转介专业机构。〔适用：0–3 岁；`机构共识`〕

**适用前提 `preconditions`**

- 月龄 0–36 月龄；以中国常住儿童及其养育人为对象。
- 用于健康科普、养育行为评估与就医提示；不替代儿科诊疗。
- 早产儿/低出生体重儿的发育监测需结合矫正月龄与医生意见。

**禁忌/不适用 `contraindications`**

- 不得据预警征象表直接下“发育迟缓/自闭症”等诊断结论。
- 不得将附件中的筛查表题目文本直接复制进产品题库（量表文本可能涉及版权，对应项目 AS-14/Q-07）。
- 不得用于 3 岁以上儿童的专属结论。

**争议标注**：`机构共识`。属“试行”指导性文件，非临床诊疗规范。

**局限**

- 面向医疗机构与养育人，操作颗粒度以咨询要点为主，不含具体疾病诊疗路径。
- “试行”版本可能更新；入库时须记录版本与复核日期。
- 附件表格未逐项数字化核验，拆条时需以官方 PDF 为准。

**建议拆分入库条目**

| --- | --- | --- | --- |
| 0–3 岁养育照护五要素是什么 | 0–3 岁 | 健康、营养、回应性照护、早期学习、安全保障 | 科普口径 |

### LIT-02 《婴幼儿早期发展服务指南（试行）》《婴幼儿营养喂养评估服务指南（试行）》

| 字段 | 内容 |
| --- | --- |
| 建议 `kb_id` | KB-LIT-002A / KB-LIT-002B |
| `kb_kind` / `domain` | `child` / `child` |
| 建议 `topic_category` | 生长发育与里程碑观察、喂养与营养、养育环境与回应性照护 |
| `age_band` | 0–6 月、6–12 月、1–3 岁（按月龄节点细分） |
| `source_type` / `source_level` | 公开文献改写 / `guide` |
| 获取状态 | **全文公开**（国家卫健委网页、中国政府网） |
| 来源 A | 《婴幼儿早期发展服务指南（试行）》，国卫办妇幼函〔2024〕467 号，成文 2024-12-05，2025-02-08 公开 |
| 来源 B | 《婴幼儿营养喂养评估服务指南（试行）》，国卫办妇幼函〔2024〕452 号，成文 2024-11-27，2025-02-08 公开 |
| 官方链接 | https://www.gov.cn/zhengce/zhengceku/202502/content_7002859.htm ；https://www.nhc.gov.cn/fys/c100078/202502/19903ff647694f3a85ed6fe332380b34.shtml |

**摘要**：两份 2025 年公开的 0–3 岁服务指南，把 2022 年版的原则性要求细化为可执行的月龄节点。A 指南规定 9 次养育风险评估与指导，B 指南规定 9 次营养喂养评估，二者均覆盖满 1、3、6、8、12、18、24、30、36 月龄。

**核心观点**

- **服务节点统一为 9 次**：满 1、3、6、8、12、18、24、30、36 月龄；新生儿期 1 次（满月），婴儿期 4 次（3、6、8、12 月龄），幼儿期 4 次（18、24、30、36 月龄）。
- **A 指南评估结构**：健康教育＋养育风险评价＋咨询指导。养育风险评价用《3 岁以下婴幼儿养育风险评估表》，一对一询问 8–10 个问题，覆盖养育行为、养育环境、养育人心理健康三类。
- **A 指南的 8 个亲子交流与玩耍月龄段**：0–1、1–3、3–6、6–9、9–12、12–18、18–24、24–36 月龄；并配《3 岁以下婴幼儿心理行为发育标志自评表》，在 3、6、8、12、18、24、30、36 月龄自评。
- **视屏时间**：0–3 岁婴幼儿应不接触任何形式的视屏类产品；2 岁以上若使用，超过 1 小时即视为养育风险。
- **B 指南喂养评价**：每日辅食从 7 类食物中选材（谷薯类、豆类和坚果类、动物性食物、蛋类、富含维生素 A 的深色蔬果、其他浅色蔬果、奶类及奶制品），不少于 4 类，且至少含 1 种富铁动物性食物、1 种蔬菜、1 种谷薯类。
- **B 指南奶量与血红蛋白**：6 月龄 800–1000 ml/日（5–6 次）；8 月龄 700–800 ml/日（4–5 次）；12 月龄 600–700 ml/日（2–3 次）；18–24 月龄 400–600 ml/日（2–3 次）。Hb≥110 g/L 为正常；90–109 轻度贫血；60–89 中度；<60 重度。
- **24–36 月龄**：逐步适应家庭膳食，每日 3 餐＋2 次加餐，正餐单独制作，进餐时间控制在 30 分钟内，少盐少糖。

**可直接引用的关键结论（改写）**

1. 0–3 岁养育风险评估应在 9 个固定月龄节点完成，而不是只做一次筛查。〔适用：中国基层儿童保健服务；`机构共识`〕
2. 养育风险不只看儿童，还看养育人的养育行为、家庭环境和心理健康；发现 1 项及以上风险即判为阳性。〔适用：0–3 岁；`机构共识`〕
3. 6 月龄后母乳提供的铁仅约占需要量的 5%，辅食必须每日包含富铁动物性食物；只加蛋黄而不加肉类，补铁量不足。〔适用：6–24 月龄；`机构共识`〕
4. 24 月龄后应逐步过渡到家庭膳食，但需单独制作、口味清淡、少盐少糖，并培养自主进食。〔适用：24–36 月龄；`机构共识`〕

**适用前提 `preconditions`**

- 月龄 0–36 月龄；中国基层儿童保健服务场景。
- 评估结果需结合健康检查、生长曲线与喂养情况综合判断，不能单题定论。
- 血红蛋白阈值适用于海平面地区；高海拔地区需按每升高 1000 米上浮约 4% 校正。

**禁忌/不适用 `contraindications`**

- 不得把“风险评估阳性”写成疾病诊断。
- 不得给出具体药物剂量、补铁剂处方或配方奶品牌推荐。
- 早产儿、低出生体重儿、慢性病儿童的评估需由医生调整。

**争议标注**：`机构共识`。属国家卫健委试行指南，非临床诊疗规范。

### LIT-11 WSAVA Global Nutrition Guidelines（全球营养评估指南）

| 字段 | 内容 |
| --- | --- |
| 建议 `kb_id` | KB-LIT-011 |
| `kb_kind` / `domain` | `pet` / `pet` |
| 建议 `topic_category` | 喂养与营养 |
| `pet_stage` / `species` | 犬猫全龄 / 犬、猫 |
| `source_type` / `source_level` | 公开文献改写 / `guide` |
| 获取状态 | **全文公开**（WSAVA PDF、JSAP 摘要） |
| 来源 | WSAVA Nutritional Assessment Guidelines Task Force（Lisa Freeman 等），2011；*J Small Anim Pract*. 2011;52(7):385–396；DOI 10.1111/j.1748-5827.2011.01079.x |
| 官方链接 | https://wsava.org/wp-content/uploads/2020/01/WSAVA-Nutrition-Assessment-Guidelines-2011-JSAP.pdf |

**摘要**：WSAVA 全球营养评估指南，把营养评估定义为继体温、脉搏、呼吸、疼痛之后的“第五生命体征”。核心是“筛查—扩展评估—干预—复评”的流程，并提供挑选商业宠粮的质询清单。指南不背书具体品牌。

**核心观点**

- 营养评估 = 第五生命体征（5VA），应在每次就诊时进行。
- 先做简短筛查（体重、体况评分 BCS、肌肉状况评分 MCS、饮食史、疾病/用药），异常再进入扩展评估。
- 扩展评估包括：当前饮食种类与量、热量密度、零食/人食/补充剂、食欲与进食行为、体重趋势、疾病与药物影响。
- 选粮质询清单关注：企业是否配备全职合格营养师、是否做饲喂试验、是否有固定配方与质量控制、是否提供完整营养分析、是否遵守 AAFCO/FEDIAF 等。
- 不背书品牌；“符合营养档案”与“饲喂试验证实”是两种不同的充足性佐证路径。

**可直接引用的关键结论（改写）**

**摘要**：生食喂养是宠物营养中真实存在的争议主题。AAHA/AAFP 明确不建议给猫饲喂未灭菌的生食或脱水动物源性食品；其依据主要是病原传播风险，而非“生食一定导致某疾病”的高等级临床因果证据。该条目应作为“机构立场”标注，不应写成绝对科学定论。

**可直接引用的关键结论（改写）**

1. 不建议给猫（及犬）饲喂未灭菌生食或脱水动物源性食品，尤其是家有儿童、老人或免疫抑制者时。〔适用：犬猫；`机构共识`，非高等级临床证据〕

**摘要**：CAPC 针对犬猫体内外寄生虫的防控指南，给出幼犬幼猫的早期驱虫时间表、成年动物全年广谱控制、粪检频次与家庭环境卫生建议。其流行病学背景为北美，中国家庭需配合中国 CDC 与《狂犬病暴露预防处置工作规范》使用。

**核心观点**

3. 成年犬猫应全年广谱防控，并按风险每年至少 2 次粪检。〔适用：犬猫成年；`机构共识`〕

| 官方链接 | 新旧国标变化解读：https://cfsa.net.cn:8899/site2/UpLoadFiles/news/upload/2021/2021-05/00376296-7929-4fbe-8db5-f8ec8cb7ce5c.pdf ；GB 10766 标准文本：http://jckspj.customs.gov.cn/spj/fileDir/resource/cms/article/4576948/4645498/2022102717020759602.pdf |

**摘要**：中国婴幼儿配方食品三项强制性食品安全国家标准，分别覆盖 0–6 月龄婴儿、6–12 月龄较大婴儿、12–36 月龄幼儿。2021 年发布、2023-02-22 实施，替代旧版 GB 10765-2010 与 GB 10767-2010 的相关内容。

**核心观点**

- 三项标准按月龄分段：GB 10765 婴儿（0–6 月）、GB 10766 较大婴儿（6–12 月）、GB 10767 幼儿（12–36 月）。
- 新国标将旧 GB 10767-2010 拆分为较大婴儿与幼儿两项标准，月龄规定更细。
- 婴儿与较大婴儿配方食品不应使用果糖、蔗糖及含果糖/蔗糖的原料作为主要碳水化合物来源；乳基产品碳水化合物首选乳糖，乳糖占碳水化合物≥90%。
- 婴儿与较大婴儿配方食品中胆碱由可选择成分改为必需成分。
- 维生素 D 等维生素指标调整为更明确的最小/最大值；污染物、真菌毒素、致病菌与营养强化剂分别受 GB 2762、GB 2761、GB 29921、GB 14880 约束。

**可直接引用的关键结论（改写）**

1. 0–6 月龄配方食品是强制标准产品，碳水化合物来源不得使用果糖/蔗糖，乳基配方乳糖占比应≥90%。〔适用：0–6 月龄；`机构共识`（强制标准）〕
2. 6–12 月龄与 12–36 月龄配方食品各有独立标准，不能用一个标准覆盖全部 0–3 岁。〔适用：6–36 月龄；`机构共识`（强制标准）〕
3. 胆碱在婴儿与较大婴儿配方中属于必需成分，不是可选添加。〔适用：0–12 月龄；`机构共识`（强制标准）〕

**适用前提 `preconditions`**

- 中国境内生产/销售的婴幼儿配方食品；0–36 月龄。
- 引用时必须写标准号、年份与实施日期（2023-02-22）。
- 具体产品合规判断需查最新配方注册与标签。

**禁忌/不适用 `contraindications`**

- 不得推荐具体品牌或配方。
- 不得把标准要求写成“某产品已达标”的结论，除非有检测/注册证据。
- 不得给出特殊医学用途配方的个体化建议。

**争议标注**：`机构共识`（强制性国家标准）。

**局限**

- 标准文本与解读页可能更新；需以国家标准全文公开系统为准。
- 不覆盖特殊医学用途婴儿配方食品（另有标准）。
- 不解决喂养方法与量的问题，需配合卫健委指南。

**摘要**：AAFCO 年度出版物汇集美国宠物食品的模型法规、犬猫营养档案、原料定义、标签范本与“complete and balanced”营养充足性佐证规则。AAFCO 是范本制定机构，不审批或认证具体产品。

**核心观点**

- 犬猫营养档案按生命阶段（生长/繁殖、成年维持等）给出最低/最高营养水平。

- 出版物还包含原料定义、标签格式、净含量、保证分析等模型规则。
- AAFCO 不是监管机关，也不对具体产品做审批/认证；各州采用其模型法规。

**可直接引用的关键结论（改写）**

1. 产品标签写“符合 AAFCO 犬/猫营养档案”与“经 AAFCO 饲喂试验证实”是两种不同的充足性声明，不能混为一谈。〔适用：犬猫；`机构共识`〕
2. 应表述为“符合 AAFCO 营养档案”，不得写“AAFCO 认证”。〔适用：知识库合规；`机构共识`〕
3. AAFCO 档案不覆盖老年/临终等所有生命阶段，老年宠物营养需另行评估。〔适用：老年犬猫；`证据有限`〕

**适用前提 `preconditions`**

- 美国市场或采用 AAFCO 体系的宠物食品；犬猫。
- 中国家庭使用需注意 AAFCO 不是中国强制标准，进口产品仍需符合中国法规。
- 引用时注明 OP 年份与具体档案（Dog/Cat Food Nutrient Profiles）。

**禁忌/不适用 `contraindications`**

- 不得写“AAFCO 认证/批准”。
- 不得把 AAFCO 档案当作治疗性处方标准。
- 不得忽略中国农业农村部公告 20 号的标签与卫生要求。

**争议标注**：`机构共识`（美国范本体系）；老年阶段覆盖为 `证据有限`。

**局限**

- 年度出版物，需购买；免费网页仅提供部分模型法规与档案。
- 美国州级采用程度不同；国际适用性有限。
- 不规定原料质量、消化率或长期健康结局。
