# 微信小程序术语表

| 术语 | 含义 |
| --- | --- |
| 小程序端 | `wechat-miniapp/` 下以 uni-app 编译为微信小程序的独立客户端。 |
| H5 端 | `frontend/` 下既有 Vue 3 Web 客户端，不因小程序建设而移除。 |
| 临时登录凭证 code | 微信 `uni.login` 返回的一次性 code，只发给小光景服务端换取会话。 |
| access token | 服务端签发、存放于小程序本地存储并用于 Bearer 鉴权的短期访问令牌。 |
| 基础同意 | `base` 类型服务协议/隐私政策同意记录；儿童信息另需独立同意，不与基础同意混淆。 |
| 问答会话 | `/qa/sessions` 创建的服务端记录；小程序端以会话 UID 读取最终分节。 |
| 测评断点 | `/assessment/start` 返回的可续答实例；每题提交后存于服务端。 |
| 合法域名 | 微信后台配置的 HTTPS API 域名；本地 `127.0.0.1` 仅供开发者工具本机联调。 |
| 小程序构建产物 | `wechat-miniapp/dist/dev/mp-weixin/` 下由 uni-app 生成、供微信开发者工具预览的客户端文件。 |
| H5 手机预览 | `frontend/` 的 Web 页面在手机尺寸或手机浏览器中的呈现；它与微信小程序构建产物是不同客户端，页面不要求逐像素相同。 |
