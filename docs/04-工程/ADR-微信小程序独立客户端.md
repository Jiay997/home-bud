# ADR：微信小程序采用独立 uni-app 客户端

- 状态：已采纳
- 日期：2026-10-12
- 背景：现有 H5 使用 Vue Router、Element Plus、`localStorage` 和浏览器 Fetch，无法直接作为微信小程序页面运行；后端已提供统一 `/api/v1` 契约与 `/auth/wx-login`。
- 决策：新增 `wechat-miniapp/`，使用 uni-app Vue 3 + TypeScript 编译到微信小程序；保留现有 `frontend/` H5。
- 认证：开发模式可使用 `/auth/dev-login` 联调；生产模式必须经 `uni.login` 获取 code 并提交给服务端 `/auth/wx-login`。服务端私密凭据不得放入小程序。
- 数据：小程序通过 HTTPS 服务端 API 访问业务数据；PostgreSQL、Milvus 与模型服务不直接暴露给客户端。
- 问答：H5 的 `fetch` SSE 消费不能直接照搬。首期以服务端会话生成和轮询读取落库分节保持兼容；是否启用微信分块能力由开发者工具实测决定。
- 后果：会增加一套客户端构建、测试和版本维护；认证、请求、存储和视觉组件需要平台适配，但 H5 发布不被阻塞。
- 验收：微信构建成功；开发者工具可导入并显示页面；开发登录、基础同意、问答及测评报告完成端到端验证；安全检查无客户端密钥。

## 落地状态（2026-10-13）

- `wechat-miniapp/` 已交付首页、问答、16 题测评与观察报告主链路；开发者工具端到端联调已通过。
- 微信小程序视觉采用“共居关系图谱 + 家庭观察档案”方向，首阶段使用 CSS 关系节点、刻度和线稿，不依赖外部图片。
- H5 `frontend/` 与微信小程序是两个独立客户端。手机浏览器打开 H5 路由（例如 `/app/start`）不会显示小程序当前首页设计，也不能作为小程序构建结果的验收依据。
- 本地验证：`npm test`（10 项通过）、`npm run type-check`、`npm run build:mp-weixin` 均通过；生产 HTTPS 合法域名、真机登录和发布审核仍未验证。
