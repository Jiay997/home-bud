## 4. S1-8 ｜误报申诉复核无人可操作

**V1.3 现状（已核对）**：§16.2 的 PA-07 只有**三行**（高风险事件列表 L3314 / 值班复核区 L3315 / 内容追溯处置区 L3316），**没有"申诉复核队列"行**，且客服在三行中全为 ❌；而 §18.4.10 的 `A-031`（L4256，误报申诉复核队列）页面标注的正是 **PA-07**；§7.9.1 状态机 L1356–1358 的 `pending_review → approved/rejected` 是**必走人工环节**。

3. §16.10 增一条可测条目："**客服可推进申诉状态，但提交复核结论的按钮与接口均不可见**"。
