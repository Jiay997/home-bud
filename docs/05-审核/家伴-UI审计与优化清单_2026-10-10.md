## P0 · 阻断级缺陷（必须修）

### P0-1 MePage 免责条文字被压成竖排单字列

- 位置：`frontend/src/views/app/MePage.vue:167`（.me-note）+ 图标同排
- 现象：`.st-note` 是 `display:flex`，子元素 `<p>` 未设 `flex: 1; min-width: 0`，
  在 flex 自由空间不足时被压到最小内容宽度，整段中文变成一列竖排字；
  同时 `.note-ico` 被拉成巨型三角（截图 `vshots/me-2.png`）。
- 影响：合规必需的 AI 免责文案完全不可读，视觉上是页面最大的一块破坏。

### P0-2 间距令牌 `--sp-5` / `--sp-1` 未定义 → 24 处间距渲染为 0

- 位置：`frontend/src/styles/tokens.scss`（只定义了 2/3/4/6/8/10/12）
- 使用方：`StartPage`、`ProfileDeleteDialog`、`AnswerCardDemo`、`HomePage`、
  `ChildProfileForm`、`ConsentModal`、`FeedbackPage`、`AppealPanel`、`PetProfileForm`、
  `ProfileListPage`、`ReportImagePage`（共 24 处）
- 现象：`var(--sp-5)` 无回退值 → 整条声明失效 → `margin/padding` 计算为 0。
  表现为卡片内元素贴边、区块之间没有呼吸感、"比例不合适"的直接来源。
- 反面：`AnswerCardDemo` 写了回退值 `var(--sp-5, 18px)`，说明作者知道它缺失。

## P1 · 明确违反 DESIGN.md 硬规则

### P1-1 emoji / Unicode 字符充当图标

DESIGN.md「Don't」首条：不用 emoji 或 Unicode 字符充当图标；图标一律为绘制的 SVG，单一描边 1.75、24 网格。

| 位置 | 违规内容 |
| --- | --- |
| `FamilyQaPage.vue:236-237` | `icon: '😊'`、`icon: '🐾'` 作为 Agent 调度管线图标 |
| `FeedbackPage.vue:195,197` | `icon: '⚠'`、`icon: '🔒'` 举报类型图标 |
| `AnswerCardDemo.vue:33,38,116,146,152` | `🔒` `🔓` `👶` `💬` `⚠` |
| 多处装饰字符 | `■`（FamilyQaPage/ReportImagePage 徽章）、`▎`（FeedbackPage 小节头）、`＋`（KbList/ProfileList）、`···`（MePage） |

### P1-2 装饰性色块 / 圆环

- `HomePage.vue:460-470` `.resume-deco`：120px 圆环 + 14px 描边，位于测评卡右上角。
  DESIGN.md 明确项目要拒绝"装饰纹理"，且该圆环与卡片内容无语义关系。
- `StartPage.vue:297-307` `.emphasis-block`：`border-left: 3px solid var(--accent)`。
  DESIGN.md 与 craft-floor 均禁止卡片/提示条上 >1px 的彩色左边框。
- `AssessmentIntroPage` 使用同类色块变体，风格尚可，但需与上面统一。

### P1-3 签到签字式"眼眉标签"（kicker / eyebrow）

DESIGN.md：不在标题上方加小标签。craft-floor：这是禁令不是默认项。

- `MePage.vue:16` `刻度档案室`
- `MemberPage.vue` `基础对比`
- `RiskBlockPage.vue` `请即刻联系专业机构`
- `AccountSecurityPage.vue` 安全层报 chip
- 后台各页 `head-sub` 副标（`临床医学认知监护词库矩阵 · 毫秒级阻断与多模态灰区干预规则`）——后台首页卡副标已到"品牌口号"长度，属于把装饰当信息。

### P1-4 浏览器自带图层未主题化

craft-floor 明确指出：选中底色、光标、滚动条、焦点环、下划线偏移必须从调色板取色，这是"被搭建过"的最便宜信号。

- 当前 `tokens.scss` 没有任何 `::selection`、`scrollbar-color`、`scrollbar-width`、`*:focus-visible` 规则。
- 滚动条在后台长表格页（`AgentLogPage`、`RiskEventPage`）非常显眼，仍是系统默认灰。

### P1-5 无 `prefers-reduced-motion` 分支

DESIGN.md GraduatedBand 规则④：reduced-motion 下在命名档位间跳变，不做插值动画。

- 全项目 0 处 `prefers-reduced-motion`。
- 受影响：`SkeletonBlock` 扫光、`GraduatedBand` 游标 `transition: left .4s`、
  `st-meter__fill` `width .3s`、各页 `transition`。

### P1-6 触控目标小于 44px

DESIGN.md：主操作位于下半屏热区且 ≥88rpx（44px）。

- `HomePage.vue:330-346` `.icon-btn` 34×34（深浅模式 / 我的入口）
- `HistoryListPage` 筛选 chips 高度约 30px
- `AdminLayout` 顶栏图标按钮
- Tab 栏图标 24px + 标签，整项可点，合格。

### P1-7 无障碍/语义缺失

- 空态插图无 `role="img"` / 无替代文本；`GraduatedBand` 未输出 `aria-label`
  （DESIGN.md 要求"必须带可读数值与 aria-label"）。
- `HomePage` 额度分段用 `role="img"` + aria-label，是正确写法，可作模板。

### P2-4 首页三个入口卡是"同尺寸卡片 = 图标 + 标题 + 文字"

craft-floor 把这种结构点名为页面脚手架级别的默认做法（lazy container）。

### P2-5 硬编码品牌态与用户身份不符

而该用户是 `member_status: free`；`MePage.vue:31` 同时显示 `免费版 · 去开通`。
两页对同一事实给出相反表述。

### P2-6 空态没有教界面

DESIGN.md：每个空态都教界面——说明建档后能得到什么，并给一个主操作。
现状是同一个对话气泡图标 + 一行字 + 主按钮，在 `profiles`、`qa_parenting`、`qa_pet`、
`qa_family`、`history` 五处复用；`history` 的空态主按钮位于首屏后需大量留白。

→ 已在第 6 批修复：`EmptyState` 扩展为 4 种场景插图 + `hint` 教学句，6 处调用全部接线。

### P2-7 后台页头信息密度 —— 经实测**不成立**，已撤回

初判依据是 1440×900 截图中首屏信息偏少，但没有量过实际数值。第 2 轮按代码实测：

| 实测项 | 值 |
| --- | --- |
| 页头卡 padding | `16px 24px` |
| 标题字号 | `--fs-title` = 19px，行高 1.35 |
| 副标字号 | `--fs-caption` = 12px，`margin-top: 2px` |
| 图标盒 | 42×42 |
| 页头卡总高 | 约 74px |

约 74px 的页头在 900px 视口里谈不上"把表格推到 400px 以下"。**这是一条凭截图印象下的错误判断，
现予撤回。** 后台页头的真实问题只有一处：部分副标内容夸大（已并入 P2-1 处理），
不构成密度缺陷，因此不做 P2-7 的重设计。
