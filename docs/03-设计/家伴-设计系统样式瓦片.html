小光景 设计系统样式瓦片 · V1.0

界面是一支量具

每一次判断都落在一条有刻度的带上，并标出它落在哪一档：月龄是区间，气质维度是三档而非唯一类型， 置信度是分档，免费额度是剩余次数，审核时限是时长。产品不说"你是哪一类"，只说"你现在在哪一段、 离安全线还有多远"。这就是这份设计系统唯一的主张。

由此推出的三条硬规则：① 不出现精确分数与绝对类型；② 语义色（危险/注意）只允许出现在刻度与状态内部， 不做装饰；③ 安全提示使用主色，因为安全是这个产品的身份，而不是又一个警告色。

本文件是 token 与组件的可视规格，不是完整页面。所有业务数值（题目、分档、时限、渠道号码）均为 合成演示数据，渠道号码按规定留空为占位；真实清单尚未确认。

色彩

克制策略：一套向主色偏移的冷中性 + 一个强调色 + 一组只服务于状态的语义色。中性色不用纯灰，否则强调色会像贴上去的。

会员不使用独立颜色。付费门控靠"内容被裁掉"与插画化的底纹表达，避免与安全、合规元素争夺颜色语义。

夜间（一等公民，不是附加项）

场景先于偏好：夜醒是核心提问场景，用户在低光下、单手、可能情绪濒临崩溃。因此夜间规则不是把浅色反相，而是三条独立约束。

压低大面积高饱和

强调色在夜间改为亮一档（#4FB3A4），但因为安全分节是实底，面积大，故底色的饱和被显著压低（#16332E）。

抬高正文对比

夜间正文对比高于浅色模式（15.6:1），补偿低光下瞳孔放大造成的眩光与失焦。

语义色同时提亮

危险与注意色在深底上重新取值，不直接复用浅色值（浅色朱红在深底上会糊成一团）。

用右上角开关查看夜间 token 的完整效果；本页所有组件共用同一套变量，没有第二套硬编码色值。

字体与数字

产品界面用一套字就够，不需要标题字体与正文字体的配对。这里是中文产品，且运行在微信小程序里： 小程序不加载远程字体（CJK 字体体积与平台限制），所以正确做法是系统中文字体栈，而不是硬塞一个网络字体。

等宽数字（量具的语言）

刻度读数必须对齐才能被扫读，因此数字一律用 tabular figures：

月龄24个月
身高92.0cm
体重13.0kg
剩余额度3 / 5次
响应耗时3.2s

等宽字体只用于真正的代码与标识

不拿等宽体当"技术感"的装饰。它只出现在知识库 ID、会话 ID、正则规则这类真的是机器读的东西上：

kb_child_sleep_03 · s_8821 · AI_GEN_LABEL_V1

药名 + (mg/kg|片|ml|每日 N 次)

中文数字当前只能使用系统自带表格数字。若后续获得可商用数字字体授权，替换 --f-num 即可，不影响任何结构。

刻度带

这是全系统的签名：标尺在上，槽在下，游标标出当前位置，档位分段由槽内的分隔承担。 标尺刻度周期固定 8px，且不随容器拉伸；间距用 4 的倍数，因此刻度、内边距与栅格同源，而不是一张装饰纹理。

五种用法，同一个组件

时长类一律按比例呈现（长度即数值），不用装饰性进度条；24h 这个数值本身是待拍板的推荐值，界面上按占位处理。

回答卡

安全分节置顶、实底铺满整宽、不可折叠；其下才是分节正文；卡脚固定免责声明与 AI 生成标识。安全分节用主色，这是本方向的核心赌注。

育儿侧建议 育儿 Agent · 3.2s

2 岁 3 月的孩子追猫，多半是在追求"它动了"这个因果反馈，而不是想伤害它。用替代动作比用"不许追"更有效。

适用前提：孩子已能听懂两步指令；猫可自主离开现场。

不建议做法：把猫按住让孩子摸。这会同时提高猫的应激与孩子的抓伤风险。

宠物侧建议 宠物 Agent · 2.8s

哈气配合竖毛多是回避信号，不是"记仇"。先增大它的可控空间，比纠正孩子更见效。

观点存在差异，建议多方参考：育儿侧主张先教孩子，宠物侧主张先改环境。

输入与错误

同意勾选：禁用必须给出理由

儿童信息的单独同意与基础同意是两个独立勾选，不能合并成一个，合并即不满足"单独同意"。

空态：教界面，不是"暂无数据"

还没有宝宝档案

建档后，回答会按孩子月龄给出，而不是通用模板。

骨架屏：形状与最终布局一致

不用屏幕中央的转圈。渐进渲染时，已返回的分节直接呈现，未返回的分节占位。

后台密度

同一套 token，密度更高。后台允许密集与批量操作，但不允许另一套视觉词汇——保存按钮在两个端必须是同一个样子。

浏览器自带的那一层

选中、光标、滚动条、焦点环、下划线偏移、表格数字——这些默认样式不属于任何设计系统，却是"这一页是被建造的" 最便宜的信号。它们全部从本系统的调色板取值。
