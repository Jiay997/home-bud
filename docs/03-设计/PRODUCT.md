## Users

**主用户：家长**。25–40 岁父母，家中以 0–6 岁幼儿为主，部分同时饲养猫狗。

使用现场（决定后续所有设计决策的物理场景）：

- **单手可操作**：一手抱孩子，另一手操作手机，主要在屏幕下半部可达区。
- **碎片时间**：安抚间隙、喂奶时、孩子睡着后。
- **夜间场景是真实高频**：夜醒是产品的核心提问场景之一，深夜低光环境下使用。
- **情绪状态可能是焦虑甚至崩溃**：出现了"高危输入被拦截"这一必须专门设计的场景。

次要用户：**后台管理员 / 内容运营 / 客服**（桌面 Web，长时间密集操作，需要密度与批量能力）、**外部专家顾问**（育儿 1 名、宠物行为 1 名，月度离线审核，不在线接待用户）。

## Product Purpose

面向家长的家庭养育科普参考工具：一个入口同时覆盖**分龄儿童养育**与**伴侣宠物科学饲养**，并能回答"孩子和宠物一起生活"这类单一工具答不全的复合问题。

成功 = 家长在 8 秒内拿到贴合自家孩子月龄、可执行、且知道自己该在什么条件下不采纳的建议；同时高危场景被可靠阻断并引导到线下专业机构。

**合规地位（产品级事实，全部文案受其约束）**：输出仅为养育参考，不替代医生、心理咨询师、学校教师、执业兽医。

## Positioning

**多智能体协同 + 安全前置**，具体到可被检验的三点：

1. **一次问、三面答**：复合问题并行调用育儿 / 宠物 / 家庭安全三个 Agent，输出固定为「安全提示置顶 → 育儿侧 → 宠物侧」。
2. **风险扫描先于一切，且钝输入侧执行**：命中高危即阻断，**不生成任何内容**，只给危机引导。
3. **给区间不给定论**：所有判定以「档位 / 区间 / 置信度」呈现（维度分三档而非唯一类型、无引用时强制标注"建议咨询专业人员"、气质明确非宿命判定）。

## Operating Context

- **问答链路**：风险扫描 → 意图识别 → 知识库检索 → 领域 Agent 并行 → 汇总（模板骨架 + 不可改写字段服务端注入）→ 输出侧过滤。
- **回答为分节结构**：建议要点 / 适用前提 / 不建议做法及原因 / 观察指标 / 何时需咨询专业人士 / 免责声明 + AI 生成内容标识。
- **性能预算**：单领域 P95 ≤8s、复合场景 ≤15s；首包为进度占位包 ≤3s，采用**分节渐进呈现**。
- **内容门控在服务端**：会员 block 由服务端裁剪正文，前端不做遮罩级安全边界。
- **合规链路是产品的一部分**：分层同意（基础同意与儿童信息单独同意必须分离）、AI 生成内容显式 + 隐式标识、个人信息权利中心、举报与处置、高风险事件值班复核。

## Capabilities and Constraints

**已确认能力**：准入与分层同意、儿童/宠物档案（多档案 + 当前问答对象）、单领域问答、家庭综合问答、气质测评（**16 题**（§12.2 冻结）/ 4 维度 / 三档 + 交叉判定）、历史与报告长图、会员月卡、风险预警与危机引导、后台最小集（知识库 / 词库 / 日志 / 反馈举报 / 高风险事件 / 权利请求 / 开关）。

**明确不做（V1.0 范围外）**：6 岁以上学科辅导；心理诊断与治疗；代做作业；宠物疾病诊断与兽药处方；宿命论性格判定与算命；直播与社区 UGC；B 端对接；多语言；非小程序首发端；**Agent 权重配置功能（已删除）**；自动续费；语音输入（移出 MVP）；专题付费内容包。

**硬约束**：

- 用词规范：禁止"心理诊断 / 治疗 / 儿科诊断 / 兽医诊疗 / **科学测评、信效度** / 包提分 / 算命 / 天生注定 / 代做作业 / 性格永久判定"；允许"养育参考 / 儿童气质测评（趣味问卷）/ 行为倾向参考 / 宠物行为科普"。
- 药名 + 剂量模式（`mg/kg`｜`片`｜`ml`｜每日 N 次）一律拦截或改写。
- 仅使用境内已备案模型；禁止用户数据用于训练。
- 留存基线：网络与操作日志 ≥6 个月；交易信息 ≥3 年；合规留档 ≥3 年。
- 无障碍底线（AS-33）：正文 ≥30rpx、说明 ≥24rpx、对比度 ≥4.5:1、可点热区 ≥88rpx。
- 技术形态约束：微信小程序**不加载远程字体**（CJK 字体体积与平台限制），必须使用系统中文字体栈。

**未决事实（记录而非编造）**：四象类型命名与理论映射（Q-06）、量表来源与"科学"宣称边界（Q-07）、问卷题量与阈值（Q-08）、iOS 支付策略（Q-25）、生成式 AI 备案（Q-32）、专家是否已签约（Q-11）、危机求助渠道清单（Q-42）、免费额度具体数值（AS-02）、总周期（D-13）。

## Product Principles

1. **安全先于完整**：安全 Agent 失败时宁可不出正文；安全分节置顶且不可折叠；危机场景不输出任何可能被误读为建议的文本。
2. **给区间，不给定论**：任何判定都以档位、区间或置信度呈现，不使用精确分数与绝对类型，避免宿命感与虚假精确。
3. **合规是界面的一部分**：免责声明、AI 生成标识、分层同意、撤回入口与举报入口都是固定位元素，不是可关闭的提示。
4. **单手可达、夜间可用**：主操作位于下半屏热区；深色模式是一等公民而非附加项。
5. **状态完备**：空、加载、失败、无权限、降级、断网、并发冲突、只读八类状态逐页定义，不允许未定义的空白页。

## Accessibility & Inclusion

- 对比度：正文与占位文本 ≥4.5:1，大字 ≥3:1（本项目把所有说明文字也纳入 4.5:1，因为免责小字承担合规作用）。
- 字号：正文 ≥30rpx；系统字号放大 1.2 倍时布局不破。
- 热区：可点击元素 ≥88×88rpx。
- 关键状态不得只用颜色区分，必须同时有图标与文字（风险、额度用尽、会员墙、降级）。
- `prefers-reduced-motion` 必须被尊重；分节渐进渲染在该偏好下退化为直接呈现。
