## 第一部分 项目背景

**1、这个项目是什么。**

我做的是一个面向家庭养育的 AI 多智能体助手，叫 Babe宝伴。只做两件事：0 到 6 岁分龄养孩子，猫狗科学养；差异在第三件事——把「孩子和宠物一起生活」这类单一工具答不全的问题一次答清。形态是一套 **uni-app** 源码出小程序和 H5，加一个后台。需求、架构、前后端与测试由我独立完成。

**2、它解决的三个核心痛点。**

第一，交叉问题没人承接。育儿工具只答孩子、宠物工具只答宠物，「孩子追猫、猫哈气」被拆成两半，安全交集没人负责。

第二，通用大模型不识别高危信号。家长崩溃时提交自伤、惊厥、误食的描述，模型照常生成——它没有「先判断该不该答」这一步。

第三，合规门槛。儿童信息属敏感个人信息，同意、撤回、删除做不扎实就是上线阻塞。

最要命的是第二条。

**3、应用场景。**

C 端家长：现场不是电脑前——单手抱娃、碎片时间、夜里低光、情绪可能正在崩溃。先建档案，再从三个入口提问，复合问题同时调三个 Agent；另外有测评、复查提醒和笔记。

P 端运营：维护知识库与词库、处置风险事件与举报、受理权利请求；专家每月离线抽审，驳回可回滚。

## 第二部分 核心功能与技术实现

**4、技术栈总览。**

一句话概括：前端一套、后端一栈、编排一图、检索双通道。

前端是 **uni-app + Vue 3 + TypeScript + Vite**，一套源码出小程序和 H5；后台是 Vue 3 加 Element Plus。后端是 **FastAPI + SQLAlchemy 2.0 + PostgreSQL 16**，Redis 7 管缓存与限流。AI 层用 **LangGraph** 编排，DeepSeek 做推理与风险分类，**Milvus** 加智谱 embedding-3 做检索。

选型主逻辑：首发只有小程序，所以用跨端源码；AI 生态在 Python，所以选 FastAPI；编排要可定序可降级，所以用显式状态图。

**5、AI 问答编排：显式状态图 + 服务端定序。**

我没写成同步接口直接问模型，而是画成一张图：风险扫描先进，命中就短路到终点；没命中才走意图路由与检索，然后扇出三条边，三个 Agent 并行，写入用 reducer 合并，最后聚合过滤。

两条硬约束：渲染顺序由服务端定，安全分节置顶不可折叠；汇总用模板骨架加字段填充，**不调模型**，免责声明和 AI 标识由服务端注入——省一次调用，也不给模型改写的机会。

**6、风险控制：两级流水线 + 两条铁律。**

一级是词库加正则，带药名剂量和语境排除，急症规则命中宠物语境就跳过，免得把宠物急症判成儿童急症。一级不命中才进二级语义：**0.8** 以上拦截，**0.5 到 0.8** 拦截并温和引导，**0.5** 以下放行打标。

两条铁律：虐待、自伤、急症、咬伤永不放行；语义模型超时或不可用一律按命中处理，不接受降级放行。命中后正文为空，只给危机引导；生成完再过一遍输出过滤。

**7、流式体验：小程序没有 EventSource。**

用 **wx.request 的 enableChunked** 逐块收 ArrayBuffer，帧格式沿用 SSE。三个真问题：sequence 跳号用最近的 section_done 覆盖；断线用 from_sequence 续传；收到 blocked 必须清空已渲染正文，不允许「灰掉但仍可读」。

**8、知识库检索：混合打分 + 三级降级。**

主通道是 Milvus 加智谱 embedding-3，2048 维 HNSW 余弦，打分 0.6 余弦加 0.4 关键词；不可用就回退进程内 3-gram hashing 到 512 维加 Python 余弦，公式不变。

这里有个真缺陷：原来只过滤零分，零星重叠就算命中，「误食布洛芬」能召回「幼儿睡眠引导」，让「建议咨询专业人士」永不触发；加相关性下限 **0.10** 才正常。

**9、计费与额度：把「什么时候不扣」写成规则。**

免费额度按上海自然日切分，正常生成扣一次；**失败、被拦截、缓存命中、断线重试都不扣**；会员不扣。并发用原子自增，还要关掉 ORM 的 session 同步，否则会二次自增。这条规则决定用户会不会因为被拦了还扣次数而流失。

**10、合规与质量工程。**

合规上：基础同意与儿童信息单独同意必须分开，敏感字段加密落库、密钥轮换、解密写审计，删除产出清单回执，AI 内容显式标识。

质量上：**113 个接口、38 张表**，**313 个后端用例**覆盖并发、幂等、降级与越权，接口文档零漂移。

**11、一句话总结。**

最大的收获是：AI 产品的门槛不在生成能力，而在边界——架构决定你敢不敢拒答，工程决定你的拒答可不可信。
