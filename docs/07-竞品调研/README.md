## 二、数据可信度说明（必须与数据同时引用）

- 全部 star / 许可 / 最近更新时间来自 **GitHub 官方 REST API 与 `raw.githubusercontent.com` 原文直连抓取**，抓取日期 **2026-10-08**；**未使用任何搜索引擎摘要**。
- **上市产品数据（`上市竞品调研_育儿与宠物.md`）与开源数据不同档**：来自公开媒体报道与行业报告（2026-10-08 WebSearch 检索），口径不一、无法逐字段复核，只用于量级判断；米卡 AI 等 AI 能力描述为官方宣传口径，未经端内实测。
- 调研期间本机 `web_search` 工具不可用（HTTP 401），`huggingface.co` 网络不可达 → **凡涉及模型权重的许可信息一律「未验证」**。
- **育儿方向的对标由本仓库自行用 GitHub search API 完成**（检索量级证据见 PRD §1.4.2 表 1）。
- `_原始检索数据/` 内的 PowerShell 脚本含**硬编码绝对路径**（原为 `D:\HomeBud\_research\...`），是从原调研位置整体迁移过来的，**直接重跑会写到旧路径**；如需复用请先改输出路径。
- 所有 star 数均为**单一时点快照**，会随时间变化。

## 三、使用边界

- 本目录是**调研证据**，不是需求文档；与 PRD §1.4 表述冲突时**以 PRD 为准**。
- 所有许可判断**仅供参考**：任何复用前必须逐条阅读 LICENSE 原件并出具法务意见（汇总见 PRD §1.4.3）。
- 方向性建议（如「多 Agent 协同不构成壁垒」）如需对外使用，须先同步市场与销售，避免把基建当卖点。
