## 范围与访客模式

- **表面**：设计系统样式瓦片（style tile）—— 双端共用的一套 token 与组件的可视规格，替代原先只有语义名、无色值的规范章节。
- **模式**：**Operate**。两端都是"用户在执行任务"：家长要拿到可执行建议，管理员要处置内容。品牌表达只活在精确的细节里。
- **不改变**：34 页线框的结构与状态、全部需求编号、全部合规硬规则。

## 受众、任务与约束

- **受众**：25–40 岁、家中 0–6 岁幼儿（部分同时养猫狗）的家长；一手抱娃、碎片时间、**深夜低光**是真实场景，情绪可能濒临崩溃。次受众为桌面端长时间密集操作的管理员。
- **任务**：拿到贴合月龄、可执行、且知道何时**不该**照做的建议；管理员判断一条内容处于什么状态、影响面多大。
- **约束（硬）**：微信小程序**不加载远程字体**（CJK 体积与平台限制）；用词规范禁用"科学测评/诊断/算命"类表述；危机渠道号码不得编造；合规元素（免责、AI 标识、同意、撤回、举报）是固定位而非可关闭提示。

## 这条品类总会交付的页面，以及它可预测的反面（两者都是窠臼，均不入候选）

- **品类默认**：粉/奶油底 + 糖果圆角卡片 + 大幅插画 + emoji + 三张等大功能卡 + "科学测评"话术。
- **可预测的反面**：冷灰金融后台 + 纯表格 + 无插画 + 无温度。

## Grounded 候选（按共鸣度排序，家族 ≥3）

1. **儿童预防接种证 / 儿保手册**（临床文书）—— 人手一本的权威实物；表格与"已确认/待办"状态天然存在；印章红只出现在确认上。
2. **家庭挂历与冰箱磁贴排班板**（家庭管理）—— 会员的"月度养育计划"本来就是一张挂历；磁贴＝可移动、可重排的条目。
3. **奶瓶 / 剂量杯 / 量勺的刻度**（家用器械）—— 深夜冲奶与喂药的真实动作；刻度分档、容量区间；把"剂量必须精确"变成视觉纪律。**← 掷骰指定**
4. **生长曲线图与百分位带**（临床测量）—— 家长唯一熟悉的"把孩子的状态画成一条线"的图形；刻度与区间是它的原生语言。
5. **婴儿监护器 / 环境检测面板**（家用仪器面板）—— 低光可读、状态优先、数值克制；承载夜间场景与"安全即主色"。
6. **急诊预检分诊牌（红黄绿分级）**（临床分诊）—— 分级色带；承载风险分级，并天然说明"分诊不是诊断"。
7. **宜家式无字组装图**（说明书）—— 分步图；承载"分阶段养育清单"，并提供一种不依赖术语的表达方式。

**家族分布**：临床文书 / 临床测量 / 临床分诊（family A）、家庭管理（B）、家用器械与仪器面板（C）、说明书（D）——跨越 4 个材料家族，未停在该题材最显眼的实物上。

无 challenger 在两轴上同时胜出，**指定方向成立**，并由落败者抬升：

- 抬升自 #1：**范围指示行** —— 页头一行字说明"你现在在哪个范围里"（把"给区间不给定论"变成常驻结构）。
- 抬升自 #2：**长度即数值** —— SLA、Agent 耗时、月度阶段一律按比例呈现，不做装饰性进度条。
- 抬升自 #3：**会员未解锁不做灰罩，而是让底纹透出**（复用一个"透出"处理）。
- 抬升自 #4：**失效但不消失** —— 到期/退款/下架/撤回统一为"保留可见 + 明确标记"，不隐藏、不删除。
- 抬升自 #5：**刻度间距、卡片内边距、栅格共享同一组 8 的倍数 token**（刻度与布局是同一个系统）。

## Direction contract

THESIS：这个产品的界面是一支**量具**——每一次判断都落在一条有刻度的带上，并标出它在哪一档；它拒绝母婴品类默认的糖果卡片、粉彩色与"科学测评"话术。
OWN-WORLD：器械白与青灰的冷中性底（中性色向主色偏移，不用纯灰）；**单一墨青强调色，且安全提示就用主色**（安全即身份）；刻度线为细墨线，数字用等宽数字（tabular figures）；语义色只允许出现在刻度与状态内部；圆角只有两档（面 12px / 控件 8px）；无渐变、无玻璃、无 emoji、无 Unicode 图标。
STORY：家长一眼看懂"我现在在哪一档、还剩多少、什么时候必须停下去找医生"；管理员一眼看懂"这条内容处在什么状态、影响面多大"。
FIRST VIEWPORT：一张回答卡——顶部安全分节以强调色实底铺满整宽且不可折叠，其下是带刻度的分档条与分节正文，底部固定免责声明与 AI 生成标识；主操作落在下半屏热区。
FORM：量具刻度系统（grounded 列表第 3 位），seed key `ea6061e3`。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
