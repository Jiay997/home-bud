育儿 Agent · 3.2s

3 岁幼儿追逐猫咪通常属于“因果机制探索”与动作模仿，并非恶意攻击。此阶段直接使用“别追”等否定词效果有限，应使用替代动作引导：

  • 示范轻柔抚触：大人握住孩子的手掌轻轻顺毛示范“慢一点摸”。
  • 退后让路礼仪：当猫走过时，引导孩子停住脚步并退后一步让路。
  • 转移玩具投射：用逗猫棒等长柄玩具介入，替代直接贴身追逐。
